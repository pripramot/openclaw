OpenClaw เชื่อมต่อ WhatsApp (ผ่าน WhatsApp Web / Baileys), Telegram (Bot API / grammY), Discord (Bot API / discord.js) และ iMessage (imsg CLI) ไปยังเอเจนต์การเขียนโปรแกรม เช่น [Pi](https://github.com/badlogic/pi-mono) ปลั๊กอินสามารถเพิ่มการสนับสนุนช่องทางเพิ่มเติม เช่น Mattermost (Bot API + WebSocket)

## เริ่มต้นที่นี่

- **ติดตั้งใหม่ตั้งแต่ศูนย์:** [เริ่มต้นอย่างรวดเร็ว](start/getting-started.md)
- **การตั้งค่าแบบแนะนำ (แนะนำ):** วิซาร์ด (`openclaw onboard`)
- **เปิดแดชบอร์ด (Gateway ในเครื่อง):** http://127.0.0.1:18789/
